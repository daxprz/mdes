# The Ultimate Muffin - Project Areas

## 1. Game Mechanics (`mechanics`)
Hit detection, collision, physics, platforming, combat feel, camera behavior.

## 2. Art & Style (`art`)
Pixel art sprites, tilesets, visual effects, animations, color palettes.

## 3. Sound & Sound Design (`sound`)
SFX, music, ambient audio, audio mixing.

## 4. Bugs (`bugs`)
Crashes, glitches, broken behaviors.

## 5. Class Mechanics (`classes`)
Per-class abilities, balance, combo systems, class identity.

## 6. User Interface (`ui`)
HUD, menus, health bars, inventory screens, tooltips.

## 7. Overall Game Design (`design`)
Game loop, progression, pacing, difficulty curve, world structure.

## 8. Items / Artifacts / Shops / Inventory (`items`)
Collectibles, crafting, weapons, shops, inventory management.

## 9. Character Progression (`progression`)
Leveling, unlocks, stat growth, artifact effects.

## 10. Enemy Design & Behaviors (`enemies`)
Enemy types, AI behaviors, spawn patterns, variety, boss design.
